# 候选版故障说明

0.5.1修复：若旧版在加密配置目录中提示“保存失败，继续使用原设置”，使用修正版后重新应用。程序保留加密、原有别名和失败时的旧配置；无需关闭Windows文件加密或删除配置。只读/权限等其他问题仍可能导致保存失败，应保留现场诊断。

| 现象 | 说明与处理 |
| --- | --- |
| 缺少运行时 | 按微软官方说明准备 .NET 10 Desktop Runtime x64；SDK不是运行必需品 |
| 提示已有实例/旧版 | 先通过该实例菜单退出，再运行目标版本；自测遇已有实例返回未执行，不替换Provider |
| 图标在隐藏区域 | 调整Windows任务栏的图标显示选项 |
| 问号/只有系统报告 | 系统报告时效未知，不参与当前电量聚合；本包未启用GATT直读，不以缓存补实时值 |
| 发现失败/列表不完整 | 保留提示，稍后手动刷新或导出诊断；不把空列表理解为检测全部成功 |
| BLE离线/状态未知 | 保持未知或历史显示；本包不代为连接、配对或清空缓存 |
| AccessDenied/标准服务缺失 | 保留诊断；在线GATT尚未宿主验证，不能据此宣布设备永远不支持 |
| 查询未结束/Draining | 原始调用未终态时不重叠查询；不要高频重试或提前释放在途对象 |
| 设置未保存 | 周期和自动开关保持旧值；未知schema或损坏配置保留且自动关闭，检查文件访问错误 |
| 诊断取消/保存失败 | 取消不写文件；换可写位置再导出，一次只执行一项导出 |
| 退出未完全收敛 | 总预算2秒后如实保留未收敛数，不能当作主动释放全部句柄 |
| ATK无接口/多个候选 | 仅接受精确目标及报告8能力，不能把FF04网页筛选项当作Windows Output通道；保留结果，不遍历试写 |
| ATK无数字或标“上次” | 点击正常托盘的“读取 ATK 电量”；自动关闭时启动不发HID；打开列表和普通刷新不额外发HID。读数5分钟后过期，失败/离线/睡眠也会失效；上次值不参与图标最低值 |
| ATK点击后暂不能再读 | 每批最短间隔10秒，进行中不叠加；可能已发请求后的异常/超时需重启应用，不能高频重试 |
| ATK会话停止重试 | 超时/异常后防止迟到响应混入新请求；保留报告，不连续重开窗口尝试，先复核原始状态和协议 |
| 电量低却没有提醒 | 提醒默认关闭；在设置中启用并应用。首次有效读数仅建基线，须后续新读数从阈值以上下降至阈值及以下；缓存/历史/离线/Mock不触发 |
| 提醒没有重复出现 | 连续低值不会重复；需新读数回升至阈值加5后再次下降才提醒。系统抑制或发送失败时跳过，不在返回桌面后补发 |
| 通知请求增加却没看到 | 请求不等于实际显示；Windows通知设置、勿扰/专注及全屏等可能影响，完整系统场景仍待验收，程序不修改这些设置 |
| 列表缺少某个设备 | 在设置“设备与托盘”中检查隐藏开关；隐藏设备仍在设置表中，可恢复默认后应用。发现新设备可关闭再打开设置 |
| 改了别名但没有生效 | 完成单元格编辑后点底部“应用”；最多48字符，控制字符被拒绝。关闭不保存，失败继续旧设置 |
| 两个同名设备设置混在一起 | 偏好按系统证据的稳定摘要关联，不按名字或发现序号；重新配对/证据变化可能需重新设置，不猜测迁移 |
| 独立图标不全 | 独立模式最多16个设备图标，按当前排序选择；系统也可能收起图标，全部设备仍在列表中 |
| 隐藏设备仍在读取 | 隐藏只影响显示/聚合/提醒；如需停止自动ATK，请在刷新页关闭自动读取 |
| 登录启动未改变 | 在“登录启动”页使用专用保存按钮；底部“应用”不操作启动项，Mock/诊断模式不提供该功能 |
| 登录启动项指向其他位置 | 先在原版本关闭自启动，再在新版本开启；不覆盖其他路径。移动目录前先关闭；超过260字符请缩短解压路径 |
| 已注册但登录后未运行 | 检查Windows“启动应用”中的开关及目录是否仍存在；注册不代表实际登录流程已验收 |

自动刷新无接口/合法离线会低频退避；已阻断时切换开关不会清除，需退出重启。周期超过5分钟时可能显示上次值，当前值有效期固定5分钟。schema4配置使用旧版时会进入不支持/不可保存状态。底部保存失败保留原周期、自动开关、提醒和显示设置；登录启动单独保存并显示实际结果。

诊断只保存在本地，发送前复查。不要用重配对、安装驱动、提权或未知HID写入作为自动修复。回退请退出候选，再启动原Phase1目录。
