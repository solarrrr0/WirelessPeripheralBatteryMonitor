解压后可直接使用根目录入口：

| 入口 | 用途 |
| --- | --- |
| `Start.cmd` | 托盘：Windows系统报告；点击“读取 ATK 电量”可读取鼠标 |
| `Check-ATK.cmd` | 独立ATK手动协议观测窗口；打开不检查/查询，按钮分别执行接口检查和单次查询 |
| `Check-Bluetooth.cmd` | 独立标准蓝牙手动验证窗口；选择符合条件的设备并点击才读取 |

切换入口前先退出原实例；两个手动入口关闭后在解压目录保存对应`.local.json`结果。它们是需要操作者明确发起通信的诊断工具，不是已验证的设备支持。

默认自动读取已配对蓝牙设备的 Windows 系统报告，标注“时效未知”；ATK 自动刷新默认关闭，自动 GATT 未启用。读取ATK：打开列表或右键菜单，点击“读取 ATK 电量”，程序自动核对唯一373B:11FD/MI01/FF02:0002接口，再依次查询在线、Duckbill Ultra型号和电量。无需另开诊断窗口。请先关闭可能占用接收器的官网驱动；不会配对或修改配置。

在设置中勾选“自动读取 ATK Duckbill Ultra 电量”并应用，可开启 5–30 分钟的独立周期，默认5分钟。保存成功后及下次正常启动时等待10秒首查；关闭设置窗口不提交修改。关闭自动刷新可随时保留手动按钮。无接口/合法离线按周期逐步退避，最长30分钟；协议异常、查询发出后的超时/取消或清理失败会停止本会话，需退出重启，切换开关不能绕过。官网共存尚未验证，使用官网或驱动时建议先关闭自动刷新。

列表区分手动/自动来源及读取时间，电量固定5分钟有效，参与总图标最低电量；之后显示“上次”并退出当前聚合。周期设为大于5分钟时，历史显示区间是正常行为。新查询开始、失败/离线/睡眠使旧值失效；自动开启且无阻断时，恢复后至少等待10秒再查询。普通“刷新”和打开列表不额外发HID；无有效直读时总图标显示问号。所有批次共用10秒最短间隔，单一在途，不排尾随批次。

旧114920构建的包外生产路径曾自动首查及一分钟三批取得100%，用户结束后官网核对一致；本包新增软件仅经假传输/程序内检查，不继承为本构建实机验收。正式ATK周期仍5–30分钟。充电状态保持未知，其他鼠标型号及官网共存未验证。

设置中可独立开启“低电量提醒”，默认关闭，阈值1–50%，默认20%。仅有效设备直读从高于阈值下降到阈值及以下时提醒一次；启动或开启时的首次读数仅建立基线。提醒后需回升至阈值加5个百分点才能再次提醒，防止20/21反复提示。系统缓存、上次值、离线、未知及Mock不触发，开启提醒不会额外查询设备。

通知使用Windows托盘通知，系统报告不宜打扰、状态未知或查询失败时跳过；被抑制/发送失败的事件不补发。最终是否显示、声音和持续时间由Windows控制，完整勿扰/专注和全屏场景尚待用户验证。多个同轮低电量设备合并提示，不强制切换焦点。

设置的“设备与托盘”页可设置别名、隐藏设备、按名称或有效电量排序，以及开启每设备图标。隐藏会从列表、总图标和提醒中排除该设备，仍可在设置恢复；底层读取不因此关闭。只有当前可靠百分比参与电量排序和图标，未知、系统缓存和历史值不冒充0%。最多保存64个设备的别名/隐藏状态；别名最多48字符；关闭不保存，底部“应用”保存成功后一起生效。

独立图标默认关闭；开启后最多显示16个未隐藏设备图标，另保留总图标供操作，超出者仍在列表中。单击任一图标打开同一列表，菜单一致。无有效百分比时显示问号；系统可能把新增图标收进隐藏区域。多电池服务仍归属于一个设备，不推测左右耳。

“登录启动”页默认关闭，使用页内“保存登录启动设置”专用按钮立即保存，底部“应用”不改启动项。只管理当前用户Run中的本程序项，指向带引号的当前EXE；不需要管理员或服务。移动/删除目录前先关闭，其他目录的同名启动项不会被覆盖，长路径超过260字符时不能启用。Windows启动应用开关和实际登录效果待验。

左键打开列表，右键刷新、设置、导出诊断、退出。关闭列表继续驻留。Windows周期为1–30分钟，ATK周期独立为5–30分钟，均默认5分钟。Mock使用内存配置且不管理自启动、不发通知；正常配置位于用户LocalAppData下PeripheralBatteryTray/config.json。schema4保存周期、ATK、提醒和显示设置，保存别名及稳定本地摘要键，不保存电量或原始设备身份。旧schema1–3迁移使用默认显示设置，既有ATK/提醒按原语义保留；损坏/未知配置保留原文件并关闭自动及提醒。详情见docs/PHASE4_DEVICE_SETTINGS.md。

真实模式的列表在首次打开时创建内容，隐藏期间保留最新状态，重新打开时显示最新快照；托盘与后台读取照常更新。

隐藏图标可在 Windows 任务栏设置中调整常显。应用不自动配对或修改设备、不上传数据。诊断包含有界ATK状态/批次及终态、提醒开关/阈值/跨越次数/通知请求及抑制错误计数；请求数不代表通知实际显示。仅在用户选择文件后本地保存，发送前请再次检查。

当前构建与验收摘要见 `release-manifest.json`、`docs/VALIDATION.json`。自动检查覆盖范围和实机待验项见 `docs/PHASE2_VALIDATION.md`；不能据自动检查宣称完整硬件/桌面验收通过。

ATK入口也可在PowerShell显式运行：

```powershell
& .\app\PeripheralBatteryTray.exe --verify-atk-host --report .\atk-host.local.json
```

它不启动蓝牙Provider，也不更改用户设置，用于保存协议观测报告；日常使用直接从托盘读取即可。先“检查接口”，再“查询一次”，行为受同一精确接口及三类命令限制。诊断工具仍保留候选观测与AcceptedPercent为空的研究边界，不推断充电状态；未点击查询为NotRun。此前实机有结构匹配的状态0/校验和0x55回复，正常托盘只接受这组已观测约束；未知状态或校验不符不显示新读数。

需要在已获准进行蓝牙通信的实机环境验证时，先退出默认实例，再在解压目录打开 PowerShell：

```powershell
& .\app\PeripheralBatteryTray.exe --verify-gatt-host --report .\gatt-host.local.json
```

窗口只列出本轮系统证据确认已配对、BLE在线且有电池服务线索的设备；没有符合目标时不发GATT。选择设备并点击“读取一次”才进行标准BAS/Uncached读取，可能涉及系统访问提示和蓝牙通信，不配对或写设备；每次至少间隔10秒，超时后等待原始调用收尾，不叠加请求。关闭窗口退出验证实例并保存结果，未点击读取保持NotRun。报告不含设备身份/完整路径；系统访问提示需操作者另行记录。单次读数不自动开启后台GATT，也不能证明左右耳/充电盒或完整兼容性。当前项目开发未运行此实机入口。
