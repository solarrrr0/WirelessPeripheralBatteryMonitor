# Phase4：设备管理、独立图标与登录启动

日期：2026-10-23。此轮沿已实现的ATK手动/可选自动刷新与低电量提醒继续，补齐别名、隐藏、排序、可选每设备图标和用户级登录启动。没有新增协议、厂商适配、设备查询周期、后台线程或运行依赖。以下软件检查不代替实机和Windows交互验收。

## 使用与规则

“设置”分为“刷新与提醒”“设备与托盘”“登录启动”三个标签页。

- 设备与托盘：别名最多48个UTF-16字符，不允许控制/方向格式字符，空白使用原名；最多为64个设备保存别名或隐藏设置。原名称仍保留在设置表格中，列表和提醒使用别名。
- 隐藏后不参与列表、总图标最低值、独立图标和低电量提醒；底层发现和已启用的读取继续，自动ATK仍需在刷新页关闭。所有设备隐藏时保留总图标，可通过设置恢复。
- 发现顺序为默认；另可按设备名称、有效直读百分比从低到高排序。无可靠百分比的档位、历史、系统缓存和未知值放到数值之后；相同数值保持发现顺序，不把离线当0%。
- 独立图标默认关闭。启用后为当前未隐藏设备各提供一个图标，同时保留总图标和操作菜单。最多16个独立图标，按当前排序选取，超出的设备仍可在列表查看；每个设备的多个电池服务合并成一个图标，不推断左右耳或盒子。
- 图标点击打开同一个列表，菜单沿用现有操作；同状态和DPI不重新绘制图标，别名只更新提示文字。隐藏、移除、回到单图标和退出时释放对应NotifyIcon和自有Icon；Explorer恢复分支重新注册现存图标。没有新增timer或轮询。
- 隐藏会移除该设备的提醒比较基线；重新显示时首次有效观测只建基线，避免把隐藏期间的下降补发为提醒。

设备表格在打开设置时取当前快照，包括已隐藏的设备。没有被本轮发现、但保存了别名/隐藏状态的条目显示为“未发现的已保存设备”，仍可清空或恢复；发现新设备后可重新打开设置。关闭不提交；“恢复所选默认”也需要点击底部“应用”才保存。

## 身份、配置与隐私

schema4在原子写入的同一个config.json中增加display（sort、iconMode、devices）。schema1–3在内存迁移为默认显示设置，不按旧版本中的同名未知字段授予新功能；已有schema2/3的ATK和schema3的提醒开关按原语义保留。未知字段保留，输入非法、重复键、未来版本或读取失败时保留原文件并拒绝覆盖；保存失败不改变内存中的有效设置。底部“应用”一次提交刷新、提醒和设备显示设置。

蓝牙的本地偏好键为SHA-256摘要，输入取已有身份解析器的分组证据并加版本前缀。进程内device:1编号继续只用于本次会话；偏好不按编号、发现顺序或名称绑定。两个同名设备不会共享设置；已确认属于同一物理设备的Classic/BLE端点沿已有证据合并。绑定中的摘要随快照、读数、睡眠失效等操作保留。摘要是稳定的本地关联键，不应当作匿名化保证。

系统分组证据改变、重新配对或系统重建身份后，偏好可能需要重新设置；程序不通过名称猜测迁移。ATK目前只有唯一精确目标，使用专用固定摘要键；不据此声称已经支持多个接收器。Mock使用独立内存偏好，不访问日常配置。

配置不保存电量、MAC、序列号、Container GUID或设备路径；保存用户自选别名与摘要。公开诊断仍从原领域模型按白名单生成，不写别名或偏好摘要。配置不是诊断导出文件，发送前需自行检查。

## 登录启动的独立保存

默认不注册自启动。正常托盘模式只在打开设置时读取当前用户Run启动项；启动程序、刷新、读取电量、底部“应用”均不会修改启动项。Mock、自测、独立诊断和资源模式不提供该功能，也不构造实际注册服务。

用户勾选“登录Windows时启动此版本”，点击同页专用“保存登录启动设置”后，才在HKCU的Run中写入PeripheralBatteryTray值，内容仅为带引号的当前包EXE绝对路径。关闭使用同一专用按钮移除本版本值。不会请求管理员权限、创建服务或计划任务；没有自动启用或迁移其他版本路径。此页与JSON分别保存，界面明确说明各自按钮的作用，避免跨文件/注册表伪称原子事务。

读取失败、非字符串值、其他程序或旧目录占用同名值时不覆盖；需先在原版本关闭该项。查询与提交前复核当前值，写入后重新读取确认；错误只显示有限提示，不公开路径或异常文本。带引号命令超过微软Run的260字符上限时禁止新启用并提示使用短路径。注册不代表Windows一定执行，启动应用开关、策略、登录顺序及实际重启仍需实测。移动/删除便携目录前应先关闭自启动。

## 软件验证及待验

新增六组必要检查DP01–DP06，直接调用生产身份解析、配置、投影、WinForms设置/列表、图标所有权和启动注册服务。它们覆盖反序枚举/同名隔离/名称变化与睡眠保留、schema迁移/未知字段/失败保存/真实隔离文件重载、0%与系统缓存过滤/隐藏/排序/诊断隐私、16图标上限/复用/回收/恢复、实际编辑单元格后应用及无额外ATK扫描、专用自启动按钮/带空格中文路径/失败冲突/长路径/模式隔离。

启动注册检查全部使用假注册表，没有创建、删除或修改用户真实启动项；设备使用假传输或构造快照，没有真实HID/GATT。程序自有DrawToBitmap用于布局检查，不是桌面截图或真实系统DPI验证。既有Core/平台/App/Mock/发布回归随最终候选统一绑定。

新实机门槛DL1：实际设置别名/隐藏/恢复/排序、关闭重开/进程重启后对应同一设备、单/多图标菜单和Windows实际DPI/Explorer恢复。SL1：真实启用/关闭、重启登录、启动应用开关与便携目录迁移流程。本轮均NotRun。AL1–AL4、NL1/NL2、在线蓝牙、真实通知、资源及24小时等既有未验项继续保留；历史100%读数属于旧114920，不移给本构建。
